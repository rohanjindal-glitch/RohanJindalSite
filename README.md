# Rohan Jindal — personal site

Static site (plain HTML, CSS, JS). No build step.

## Update content
- Blog posts: `content/posts.js` (add a new block at the top)
- Photos: put the image in `images/`, then add a line in `content/photos.js`
- Book and chapters: `content/book.js`
- Links, intro text: `content/site.js`

## Run locally
```
npx http-server . -p 4173
```

Deployed on Vercel at https://rohanjindal.in
